隱私權政策

版本日期：2026 年 10 月 9 日｜本頁於公開發布時生效

1．適用範圍與營運者

本政策描述 LINE Assistant Calendar 及其小助理功能處理個人資料的方式。日曆整合目前在本機驗證階段，雲端日曆功能尚未正式啟用。本服務限營運者本人使用；未來擴大使用者範圍時，須先更新政策與資料隔離設計。

營運者：LINE 小助理維護者
支援信箱：yushulu@gmail.com

2．處理哪些資料

  • LINE 傳送的文字、使用者識別碼與訊息識別碼，用來判斷指令、回覆與確認行程歸屬。
  • 記事內容、記帳項目與金額、提醒內容與時間，以及功能所需的建立時間與狀態。
  • 行程標題、日期、開始與結束時間、地點、指定日曆識別碼、確認碼及處理狀態。
  • Google OAuth 存取權杖、更新權杖及相關用戶端資訊，用來存取已授權的日曆。
  • 為查明重複新增或不明結果，讀取由本助理建立的對應 Google 活動。連線測試可能讀取活動回應，但不將活動內容顯示在公開網站。

3．用途與 Google 存取範圍

資料僅用於提供記事、記帳、提醒、日曆草稿、使用者確認、活動新增與結果核對。日曆權限 calendar.events 提供活動讀取與管理能力，但目前功能不提供批量讀取、既有活動修改或刪除。

日曆資料不出售、不用於廣告或建立廣告畫像。本次日曆整合不將 Google 日曆資料送交生成式 AI 模型，也不用來訓練一般用途 AI 模型。Google API 資料的使用與傳輸應遵循 Google API Services User Data Policy，包含 Limited Use 要求。

4．資料傳輸與第三方

訊息透過 LINE 平台傳送；確認後的活動資料送至 Google Calendar。LINE 回覆會包含草稿內容與確認指令。小助理既有雲端服務使用 Railway；日曆整合若經後續確認部署，其行程草稿與授權更新快取也會由該託管環境處理。實際雲端機密存放方式尚待確定，未在本次準備工作中上傳。

本說明網站由 GitHub Pages 託管，不提供資料輸入、Google 登入、追蹤程式或分析工具。GitHub 會為安全目的記錄並保存訪客 IP 位址，無論訪客是否登入 GitHub；其處理方式適用 GitHub 隱私聲明。

5．保存與保護

記事、記帳與提醒保存在小助理資料庫；日曆草稿另行保存。確認碼有效期為 10 分鐘，但到期不代表草稿資料自動刪除。目前尚無自動清理已完成、取消或過期草稿的功能，也未設定固定自動刪除天數。

Google 活動保留在使用者的日曆中，直到使用者自行刪除。撤銷授權不會自動刪除已新增的活動或小助理草稿。OAuth 原始憑證與可選更新快取由營運者限制存取，不應放入公開網站或公開程式碼儲存庫。備份安排與清理期限須在日曆雲端功能正式啟用前由營運者確認，不承諾立即清除所有備份副本。

6．誰能接觸資料

目前營運者本人負責管理服務與授權資訊，必要時可查閱資料庫以維護功能或處理刪除。未授權他人查看或使用行程資料。託管平台及 Google、LINE 在提供各自服務所需範圍內處理資料，適用其服務條款與隱私政策。

7．撤銷與刪除

可在 Google 帳號的第三方連線設定移除本應用程式的存取權，停止後續日曆存取。記事、記帳與未執行提醒可透過既有刪除指令處理；Google 活動需在 Google Calendar 手動刪除。

目前沒有 LINE 指令可清除所有日曆草稿或 OAuth 快取。營運者需在維護模式中處理草稿與快取刪除，避免破壞其他小助理資料。若需要查詢或刪除助理保存的資料，可聯絡 yushulu@gmail.com，由營運者確認並處理。

8．政策變更

功能、託管平台、資料用途或使用者範圍變更時，更新本政策與日期；涉及新的 Google 權限時，須另取得所需授權。本政策不表示任何尚未部署的功能已上線。
